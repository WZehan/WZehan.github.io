## Other Products

### BiliPod

A music-focused Bilibili listening experience built entirely with Codex during June–July 2026 as a vibe-coding project. The cross-platform client uses Flutter, while Supabase handles authentication and data management and Resend provides email verification. Because the project may carry copyright risks, it is not intended for broad distribution; TestFlight and Google Play testing links are available on the product page.

- [Product page and beta downloads](https://bilipod.com)

### 3DGS Gallery

An online gallery of my 3D Gaussian Splatting scenes. The PLY files are generated with Apple's open-source SHARP model, hosted on object storage, and presented as interactive web scenes with SuperSplat.

- [Open the gallery](https://3dgs-gallery.wangzehan.com/)
